# 🎬 Estúdio

Texto ou imagem → vídeo com movimentos de câmera prontos (Dolly In, Crash Zoom, Órbita 360…),
usando o modelo aberto LTX-Video 0.9.8 destilado no ZeroGPU.

Cada visitante usa a própria cota de GPU do Hugging Face: entre na sua conta para ter 5 min por dia.

Código: https://github.com/gutodrac-spec/Jarvis/tree/estudio-video/estudio
