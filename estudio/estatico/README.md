# 🎬 Estúdio

Página estática (grátis em qualquer conta) que gera vídeos usando o Space oficial
[Lightricks/ltx-video-distilled](https://huggingface.co/spaces/Lightricks/ltx-video-distilled)
como motor. Cada visitante entra com a própria conta do Hugging Face e usa a própria cota de GPU.

Código: https://github.com/gutodrac-spec/Jarvis/tree/estudio-video/estudio/estatico
