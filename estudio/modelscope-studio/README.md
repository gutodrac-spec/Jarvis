# 🎬 Estúdio

Texto ou imagem → vídeo com movimentos de câmera prontos (Dolly In, Crash Zoom, Órbita 360, Drone FPV…),
usando o modelo aberto LTX-Video 0.9.8 destilado na GPU (xGPU) do ModelScope.
Os pesos vêm do Hugging Face.
